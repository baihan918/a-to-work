# Array 题目索引

## 核心套路

数组题常见思路：

- Hash Table：适合快速查找“另一个数是否出现过”、统计出现次数。
- Two Pointers：适合有序数组、排序后查找组合、左右收缩。
- Sorting：常用于去重、制造单调性，再配合双指针。
- 分组降维：多数组求和时，把 `O(n^4)` 拆成两个 `O(n^2)`。

## 复习重点

### Hash Table

看到“找另一个数”“统计组合数量”“频次匹配”时优先考虑哈希表。

核心问题是：`Map` 里到底存什么。

- 两数之和：存 `num -> index`。
- 四数相加 II：存 `sum -> count`。

### Two Pointers

双指针通常依赖有序性。

如果数组本身无序，但题目允许改变顺序或只要求返回数值组合，可以先排序。

三数之和的移动规则：

- `sum < 0`：左指针右移，让和变大。
- `sum > 0`：右指针左移，让和变小。
- `sum === 0`：记录结果，左右都去重后继续收缩。

### 去重

需要返回“不重复组合”的题，去重通常比主逻辑更容易出错。

三数之和要处理两层去重：

- 固定数 `nums[i]` 去重。
- 找到答案后，`left` 和 `right` 指向的值都要去重。

### 计数 vs 返回组合

先判断题目是“统计数量”还是“返回具体组合”。

- 统计数量：更适合用哈希表记录次数。
- 返回不重复组合：更常见是排序 + 双指针 + 去重。
