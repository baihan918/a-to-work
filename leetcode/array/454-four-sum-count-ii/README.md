# 454. 四数相加 II

## 分类

- Array
- Hash Table

## 题目目标

给定四个整数数组 `nums1`、`nums2`、`nums3`、`nums4`，统计有多少个四元组 `(i, j, k, l)` 满足：

```js
nums1[i] + nums2[j] + nums3[k] + nums4[l] === 0
```

## 解题思路

这题不要用“四数之和”的排序双指针思路，因为这里是四个独立数组，目标是统计组合数量。

核心做法是把四个数组拆成两组：

1. 枚举 `nums1 + nums2` 的所有结果，用 `Map` 记录每个和出现了几次。
2. 枚举 `nums3 + nums4` 的所有结果，查找 `Map` 中是否存在它的相反数。

因为：

```js
a + b + c + d === 0
```

等价于：

```js
a + b === -(c + d)
```

所以只要知道前两个数组中某个和出现了几次，就能快速统计后两个数组对应的匹配数量。

## 复杂度

- 时间复杂度：`O(n^2)`
- 空间复杂度：`O(n^2)`

## 易错点

- `Map` 里存的是“和出现的次数”，不是只存是否出现。
- 统计答案时要累加次数，因为可能有多个 `(a, b)` 组合得到同一个和。
- 这题是计数问题，不需要去重。
