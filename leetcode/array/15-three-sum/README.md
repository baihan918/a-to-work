# 15. 三数之和

## 分类

- Array
- Two Pointers
- Sorting

## 题目目标

给定一个整数数组 `nums`，找出所有和为 `0` 且不重复的三元组：

```js
nums[i] + nums[j] + nums[k] === 0
```

要求返回的三元组不能重复。

## 解题思路

这题的关键是先排序，再用双指针把三数问题转成两数问题。

整体流程：

1. 先对数组升序排序。
2. 枚举第一个数 `nums[i]`。
3. 在 `i` 右侧使用双指针：
   - `left = i + 1`
   - `right = nums.length - 1`
4. 计算三数之和：
   - 如果 `sum === 0`，记录答案，然后移动左右指针并跳过重复值。
   - 如果 `sum < 0`，说明和太小，移动 `left` 让和变大。
   - 如果 `sum > 0`，说明和太大，移动 `right` 让和变小。

## 为什么要排序

排序后可以利用数字大小关系移动指针：

- 当前和太小，说明需要更大的数，所以 `left += 1`。
- 当前和太大，说明需要更小的数，所以 `right -= 1`。

排序也让去重更简单：相同数字会挨在一起。

## 去重逻辑

三数之和最容易错在去重。

外层枚举 `i` 时，如果当前值和前一个值相同，要跳过：

```js
if (i > 0 && nums[i] === nums[i - 1]) continue;
```

找到一组答案后，左右指针也要跳过重复值：

```js
while (left < right && nums[left] === nums[left + 1]) left += 1;
while (left < right && nums[right] === nums[right - 1]) right -= 1;
```

然后再同时移动：

```js
left += 1;
right -= 1;
```

## 剪枝

排序后，如果 `nums[i] > 0`，后面的数也都大于等于 `nums[i]`，三数之和不可能再等于 `0`，可以直接结束循环。

## 复杂度

- 时间复杂度：`O(n^2)`
- 空间复杂度：通常记为 `O(1)`，不计算排序所需空间和答案数组。

## 易错点

- 不能用简单哈希直接做，因为题目要求返回不重复三元组。
- 排序时必须写比较函数：`nums.sort((a, b) => a - b)`。
- 外层 `i` 要去重。
- 找到答案后，`left` 和 `right` 都要跳过重复值。
