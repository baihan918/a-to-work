# 1. 两数之和

## 分类

- Array
- Hash Table

## 题目目标

给定一个整数数组 `nums` 和一个整数目标值 `target`，在数组中找出和为 `target` 的两个数，并返回它们的数组下标。

题目保证每组输入只对应一个答案，并且同一个元素不能使用两次。

## 解题思路

暴力做法是两层循环，枚举所有数字组合，时间复杂度是 `O(n^2)`。

更好的方式是用 `Map` 记录已经遍历过的数字和下标。

遍历每个数字 `num` 时，计算它需要的另一个数：

```js
need = target - num
```

如果 `need` 已经在 `Map` 中，说明之前出现过一个数字可以和当前数字组成目标值，直接返回两个下标。

如果没有找到，就把当前数字和下标存入 `Map`，留给后面的数字匹配。

## 为什么先查再存

因为题目要求同一个元素不能使用两次。

如果先把当前数字存入 `Map`，当 `target = num * 2` 时，可能会误用当前元素自己。

## 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

## 易错点

- `Map` 存的是数字到下标的映射：`num -> index`。
- 遍历时先查 `need`，再存当前 `num`。
- 返回的是下标，不是数字本身。
