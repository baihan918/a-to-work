# 567. 字符串的排列

## 分类

- String
- Sliding Window
- Hash Table

## 题目目标

给定两个字符串 `s1` 和 `s2`，判断 `s2` 中是否包含 `s1` 的某个排列。

换句话说，要判断 `s2` 中是否存在一个长度等于 `s1.length` 的连续子串，并且这个子串的字符种类和出现次数都和 `s1` 一样。

示例：

```js
s1 = 'ab';
s2 = 'eidbaooo';
```

`s2` 中包含 `'ba'`，它是 `'ab'` 的排列，所以返回 `true`。

## 解题思路

这题找的是固定长度的连续窗口，窗口长度就是 `s1.length`，所以适合用滑动窗口。

核心流程：

1. 统计 `s1` 中每个字符出现次数，记为 `need`。
2. 在 `s2` 中维护一个长度为 `s1.length` 的窗口，统计窗口内字符出现次数，记为 `window`。
3. 每次窗口向右滑动一位：
   - 加入右侧新字符。
   - 移除左侧旧字符。
4. 如果某个窗口的字符频次和 `need` 完全一致，说明找到了 `s1` 的一个排列。

## 为什么不是普通子串查找

普通子串查找要求顺序完全一致，比如 `'ab'` 只能匹配 `'ab'`。

这题要求的是排列，所以 `'ab'` 可以匹配 `'ab'`，也可以匹配 `'ba'`。

## 复杂度

- 时间复杂度：`O(26 * n)`，因为每次比较 26 个小写字母，通常可视为 `O(n)`。
- 空间复杂度：`O(26)`，也就是 `O(1)`。

## 易错点

- 题目要求的是连续子串，不是子序列。
- 匹配的是排列，不要求字符顺序和 `s1` 一样。
- 窗口长度必须固定为 `s1.length`。
- 如果 `s1.length > s2.length`，直接返回 `false`。
