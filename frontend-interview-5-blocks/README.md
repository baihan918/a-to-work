# 9 年前端面试准备：5 块能力题库

这份材料按 9 年前端面试的真实考察方式组织，不按零散八股组织。目标不是背概念，而是把基础、React、浏览器、工程化和项目架构连到真实业务经验里。

## 目录

1. `01-react-depth`：React 深度
2. `02-browser-fundamentals`：浏览器原理
3. `03-engineering`：工程化
4. `04-project-architecture`：项目架构
5. `05-js-ts-foundation`：JS / TS 基础

每个目录下：

- `README.md`：核心题解和答题口径。
- `BIG_FACTORY_QUESTIONS.md`：参考字节、蚂蚁、阿里等大厂公开面经风格整理的追问题库。

## 使用方式

- 第一轮：每块挑 10 个高频题，先能讲出 60 秒答案。
- 第二轮：每个答案补一个你自己的项目例子。
- 第三轮：把性能优化、复杂页面、工程化提效 3 个项目故事打磨成可追问版本。
- 第四轮：做 mock，把回答压缩到“结论、原理、项目、取舍”四段。

## 9 年前端答题原则

- 不要只回答 API 用法，要回答背后的机制和工程取舍。
- 不要只说“我优化了”，要说“怎么定位、怎么改、数据变化是什么”。
- 不要只讲个人代码技巧，要讲团队成本、质量基线、稳定性和长期维护。
- 不要无限准备，技术题必须服务于项目故事和岗位匹配。

## 大厂风格提醒

- 字节风格：基础追问深、节奏快，常把浏览器、JS、React、算法和手写题串起来问。
- 蚂蚁风格：重工程稳定性、业务复杂度、组件体系、表单/中后台/质量治理。
- 阿里风格：重基础体系、工程化、架构取舍、项目影响和横向协作。
- 这些题不是承诺某家公司一定会问，而是参考公开面经和常见社招追问方式整理，用来训练回答密度。
